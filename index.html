Tilt Sensor Alarm System — Lab Report

SW-520 tilt sensor → 2N2222 NPN transistor → LU-5-R relay → buzzer + LED alarm. Built on real breadboard and TinkerCAD. Level 2.6 · May 2026.

Academia.edu ↗ SlideShare ↗ ▶ YouTube Demo ↗
+

Project Overview

#SectionContent
01ObjectiveSW-520 tilt sensor acts as digital trigger — when tilted past ~45°, activates relay alarm
02Transistor Switch2N2222 NPN — base driven via 1kΩ R_B; 10kΩ pull-down holds base at GND when sensor open
03Relay ControlLU-5-R 9V relay (coil ~200Ω) — transistor saturation energises coil, pulls COM to NO
04Protection1N4148 flyback diode across relay coil — clamps back-EMF spike on de-energisation
05OutputRed LED (470Ω limiting resistor) + active buzzer — both activate simultaneously on tilt
06ImplementationBuilt and tested in TinkerCAD simulation + real breadboard. Video published on YouTube.

Components

ComponentModel / ValueRole in Circuit
Tilt SensorSW-520Ball-type digital switch — closes at ≥45° tilt, opens when flat
Pull-down Resistor10kΩHolds base at 0V when sensor open — prevents false trigger from floating pin
Base Resistor1kΩLimits I_B into 2N2222; ensures safe saturation without overdrive
NPN Transistor2N2222Electronic switch — I_C max 600mA, hFE 100–300; saturates to drive relay coil
Flyback Diode1N4148Reverse-biased across relay coil — dissipates back-EMF spike on turn-off
RelayLU-5-R (9V)Electromechanical switch — coil R ≈ 200Ω; NO+COM connect load when energised
LED Resistor470ΩLimits LED current to ~14.9mA — within safe 10–20mA range
LED5mm RedVisual indicator — V_F ≈ 2.0V, I_F max 30mA
BuzzerActive 9VInternal oscillator — sounds on DC power, no external frequency needed
Power Supply9V BatteryPowers entire circuit — relay coil, buzzer, LED

Key Calculations

CalculationFormulaResult
Relay coil current (I_C)I_C = (V_supply − V_CE(sat)) / R_coil(9 − 0.2) / 200 ≈ 44 mA
Min base current for saturationI_B(min) = I_C / hFE × 1044/100 × 10 = 4.4 mA required
Actual base currentI_B = (V_supply − V_BE) / R_B(9 − 0.7) / 1000 = 8.3 mA ✓
LED currentI_LED = (V_supply − V_F) / R_LED(9 − 2.0) / 470 ≈ 14.9 mA ✓

Circuit Logic

StateSensorTransistorRelayOutput
FlatOpenCutoff — I_B = 0De-energisedBuzzer OFF · LED OFF
Tilted ≥45°ClosedSaturation — I_B = 8.3mAEnergisedBuzzer ON · LED ON ✓
